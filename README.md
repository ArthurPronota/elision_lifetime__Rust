# Правила elision lifetime в Rust

## Что такое elision

**Elision** (пропуск) — это набор **детерминированных правил**, по которым **компилятор** сам **вставляет** lifetime-аннотации за вас. Благодаря elision во многих случаях **не нужно** писать `'a` **вручную**.

## Где применяется

**Elision** работает **только** в **сигнатурах**:

| Место | Elision? |
|---|---|
| **Функции** | ✅ Да |
| **`impl`-методы** | ✅ Да |
| **Тела функций** | ❌ Нет |
| **Определения `struct`** | ❌ Нет |
| **`enum`** | ❌ Нет |

**В `struct`** и **`enum`** lifetime нужно указывать **явно**.

## Три правила elision

Применяются **по порядку**:

### Правило 1: каждая входная ссылка — свой lifetime

```rust
fn foo(a: &str, b: &str) { ... }
```

**Компилятор** видит:

```rust
fn foo<'a, 'b>(a: &'a str, b: &'b str) { ... }
```

Каждой **входной** ссылке — **свой** lifetime.

### Правило 2: одна входная → её lifetime всем выходным

```rust
fn foo(a: &str) -> &str { ... }
```

**Компилятор** видит:

```rust
fn foo<'a>(a: &'a str) -> &'a str { ... }
```

Если **ровно одна** входная ссылка — **её** lifetime → **всем** выходным.

### Правило 3: `&self`/`&mut self` → его lifetime всем выходным

```rust
impl Foo {
    fn method(&self) -> &str { ... }
}
```

**Компилятор** видит:

```rust
fn method<'a>(&'a self) -> &'a str { ... }
```

Если есть **`&self`** или **`&mut self`** — **его** lifetime → **всем** выходным.

## Разбор вашего примера

### `first_byte`

```rust
fn first_byte(s: &str) -> &str {
    &s[0..1]
}
```

**Применяем elision:**

1. **Правило 1:** `s: &'a str`.
2. **Правило 2:** **одна** входная → `-> &'a str`.

**Компилятор** видит:

```rust
fn first_byte<'a>(s: &'a str) -> &'a str { ... }
```

✅ **Аннотация не нужна** — elision **сработал**.

### `Cashe` (struct)

```rust
struct Cashe<'a>(&'a str);
```

❌ **Elision не применяется** к `struct` — lifetime **явно**.

### `impl<'a> Cashe<'a>`

```rust
impl<'a> Cashe<'a> {
    fn get(&self, key: &'a str) -> &str {
        if self.0.starts_with(key) {
            self.0
        } else {
            first_byte(self.0)
        }
    }
}
```

**Применяем elision к `get`:**

1. **Правило 1:**
   - `&self` → `&'b self`;
   - `key: &'a str` (уже аннотирован).
2. **Правило 2:** **не** применяется — **две** входные ссылки.
3. **Правило 3:** есть **`&self`** → `'b` → **всем** выходным.

**Компилятор** видит:

```rust
fn get<'b>(&'b self, key: &'a str) -> &'b str { ... }
```

**Возврат** — `&'b str` (lifetime `self`).

### Почему это работает

```rust
let v = Cashe("abcdef");
let r1 = v.get("abc");
println!("{}", r1);   // abcdef
```

- **`v`** живёт **до конца** `main`.
- **`r1`** живёт **не дольше** `v`.
- **`self.0`** — `&'a str` (lifetime `"abcdef"`).
- **`first_byte(self.0)`** — возвращает `&'a str`.
- **Оба** варианта возвращают ссылку, живущую **не меньше** `'b`.

✅ **Компилируется**.

## Когда elision **не** сработает

### 1. Несколько входных ссылок без `&self`

```rust
fn longest(a: &str, b: &str) -> &str { ... }
```

**Ошибка:**

```
error[E0106]: missing lifetime specifier
```

**Причина:** **две** входных, правило 2 **не** применяется.

**Решение:**

```rust
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str { ... }
```

### 2. Возврат ссылки, не связанной со входом

```rust
fn foo() -> &str { "hello" }   // ❌
```

**Ошибка:**

```
error[E0106]: missing lifetime specifier
```

**Решение:**

```rust
fn foo() -> &'static str { "hello" }   // ✅
```

**`'static`** — **явно**.

### 3. `struct` со ссылкой

```rust
struct Foo {
    x: &str,   // ❌
}
```

**Ошибка:**

```
error[E0106]: missing lifetime specifier
```

**Решение:**

```rust
struct Foo<'a> {
    x: &'a str,
}
```

## Сводная таблица

| Ситуация | Elision? | Результат |
|---|---|---|
| **1 вход → 1 выход** | ✅ | `'a` → `'a` |
| **N входов → 1 выход, без `&self`** | ❌ | Нужна явная |
| **`&self` → выход** | ✅ | `'self` → выход |
| **Нет входов → выход** | ❌ | Нужна `'static` |
| **`struct` со ссылкой** | ❌ | Явная `'a` |

## Сводная таблица правил

| # | Правило | Пример |
|---|---|---|
| **1** | Каждый вход — свой `'a` | `fn f(a: &str, b: &str)` |
| **2** | 1 вход → его `'a` всем выходам | `fn f(a: &str) -> &str` |
| **3** | `&self` → его `'a` всем выходам | `fn m(&self) -> &str` |

## Практический пример

```rust
// ✅ Elision работает
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

// ✅ Elision работает (метод)
impl Parser {
    fn peek(&self) -> &str {
        &self.input[0..1]
    }
}

// ❌ Elision не работает
fn longest(a: &str, b: &str) -> &str { ... }

// ✅ Явная аннотация
fn longest<'a>(a: &'a str, b: &'a str) -> &'a str { ... }

// ❌ Struct — нет elision
struct Parser {
    input: &str,
}

// ✅ Явно
struct Parser<'a> {
    input: &'a str,
}
```

| Аспект | Описание |
|---|---|
| **Elision** | Автовывод lifetime |
| **Где** | Только сигнатуры |
| **Правил** | 3 |
| **Порядок** | По порядку |
| **`struct`** | Не применяется |
| **Тело** | Не применяется |

## Итог

- **Elision** — **автовывод** lifetime в **сигнатурах**.
- **Три правила:**
  1. Каждый вход — **свой** `'a`.
  2. **Один** вход → его `'a` **всем** выходам.
  3. **`&self`** → его `'a` **всем** выходам.
- **Работает** для функций и `impl`-методов.
- **Не работает** для `struct`/`enum` и **тел** функций.
- **Не сработает:** N входов без `&self`, возврат без входа.
- **В вашем примере:**
  - `first_byte` — elision (1 вход);
  - `Cashe<'a>` — **явно** (struct);
  - `get` — elision (`&self` → правило 3).
- **Правило:** если **один** вход или `&self` → elision; иначе — **явная** `'a`.
